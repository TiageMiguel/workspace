# Workspace

This Raycast extension has **moved to [Vicinae](https://github.com/TiageMiguel/workspace-vicinae)**.

The Raycast Store is not a real store. It does not allow competitions, so this extension cannot be published there. Development continues on [Vicinae](https://vicinae.com), an open source alternative.

The Raycast version is **unmaintained**. No support, no updates.

Use **[workspace-vicinae](https://github.com/TiageMiguel/workspace-vicinae)** instead.
